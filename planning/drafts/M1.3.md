## Scope

- Create a fixed query script against the private bus for UUID/PID/title/class/client and frame geometry/active identity with explicit unavailable values and encoded dynamic data.
- Probe activation followed by observed focus, vanished-window behavior, timeout/script cleanup, JSON result ordering and repeated query latency.
- Record retain/replace evidence; custom JSON alone does not justify replacing kdotool.

## Acceptance criteria

- [ ] The real fixture is discovered without accessibility, exact client bounds are recorded and success requires observed focus rather than a successful subprocess exit.
- [ ] Slow/failed queries terminate within a recorded limit and leave no query scripts/processes; measurements support a proposed bounded polling interval or record a blocker before production integration.
