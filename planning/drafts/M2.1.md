## Outcome

An installable Python CLI exposes explicit command contracts and stable machine-readable failures.

## Milestone

#2

## Dependencies

#1

## Scope

- Add packaging and command parsing for doctor; session start/status/stop; launch/windows/focus/wait; key/type/click/input reset; screenshot/logs; close/kill, with documented flags/defaults and headless mode.
- Specify JSON result/error envelopes, meaningful exit statuses and stable codes for each required failure class; include request/generation identifiers, partial outcomes and handles where available.
- Accept --generation on every session-addressed command; document current-generation name lookup, dispatch semantics and no automatic launch/input retry on unknown completion. Unwired operations explicitly fail.

## Acceptance criteria

- [ ] CLI contract checks cover success/error examples, invalid flags/arguments and unsupported commands in JSON mode; stdout has only the result and diagnostics use stderr or files.
- [ ] No supported command path requires a prompt; blocking command contracts name finite worker-enforced limits, and future viewer mode does not require a backend framework.
