## Outcome

Separate CLI invocations can address one persistent worker through a private versioned protocol with identity checked before dispatch.

## Milestone

#2

## Dependencies

#14

## Scope

- Define framing/version validation, bounded request reads, request IDs, operation arguments, finite timeouts and structured replies over an owner-only Unix socket.
- Resolve generation-qualified session/application/window references and reject mismatches before dispatch; correlate transport failures and partial/uncertain outcomes.
- Provide the worker entrypoint and transport lifecycle without retaining connections or desktop state in the CLI.

## Acceptance criteria

- [ ] Two independent CLI processes contact the same worker and generation; malformed/incompatible protocol and stale references produce stable errors without action side effects.
- [ ] Socket/runtime permissions restrict access to the owner; worker/subprocess logs cannot enter the protocol or JSON output. A lost response is not automatically retried as launch or input.
