## Outcome

CLI and worker share normalized paths and durable generation-specific manifests/log locations.

## Scope

- Normalize relative application cwd, artifact root and screenshot output against caller cwd before transport; define omitted cwd, slash-containing executables, final PATH lookup and environment precedence.
- Allocate collision-free generation/request artifact paths outside disposable settings and atomic manifest updates; define logging interfaces shared by supervisor/apps/adapters.
- Record mode/output/dependency provenance, argv/cwd, process and target references, partial outcomes, cleanup status and terminal outcome, without dumping credentials or the inherited environment.

## Acceptance criteria

- [ ] Checks from a directory different from the worker verify all relative/default path cases and executable-resolution contracts.
- [ ] Repeated allocations do not collide, interrupted manifest writes preserve a valid prior record, and all required schema fields have defined producers.
- [ ] A simulated failed startup/terminal cleanup retains artifact records and preserves an already-recorded failure; M3/M6 wire the real producers and artifact access.
