## Outcome

Private KWin, adapters and trusted applications receive explicit isolated desktop/settings endpoints.

## Milestone

#3

## Dependencies

#18

## Scope

- Create owner-only runtime/control storage and disposable HOME/XDG settings, launch observed private D-Bus and KWin children with one headless 1280×720 scale-1 output.
- Centralize application environment construction: strip host DISPLAY/XAUTHORITY/Wayland/D-Bus/accessibility endpoints, apply allowed overrides, then install private protected settings and reject protected overrides.
- Keep host user-manager access confined to lifecycle control and any EIS/ScreenShot2 permission adjustments confined to the created compositor; retain trusted project/network access.

## Acceptance criteria

- [ ] A real environment-reporting child has the intended private endpoints/settings and can read its project files; protected override attempts fail before launch.
- [ ] Contaminated host environment tests show neither adapters nor applications fall back to personal display/accessibility/clipboard endpoints; runtime sockets/files are owner-only.
- [ ] No global KDE configuration is changed; private settings are disposable and artifact roots remain outside them.
