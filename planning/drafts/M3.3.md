## Outcome

Session state reflects live capabilities and essential process health instead of persisted files alone.

## Milestone

#3

## Dependencies

#19

## Scope

- Implement starting/ready/stopping/stopped/failed states and monitor worker service, bus and compositor health.
- Require control connectivity, structured window query, resumed input device and screenshot probe before ready; adapt the real M1 probes behind interfaces until production adapters arrive in M7.1.
- Bound readiness/subprocess/pipe waits; reject desktop work on essential failure and initiate the cleanup path. Supply structured health/prerequisite details for doctor/status.

## Acceptance criteria

- [ ] Socket appearance alone cannot make the session ready; each missing capability causes a specific startup failure with retained diagnostics.
- [ ] Independent bus/compositor death and worker death/unresponsiveness produce unavailable status based on live observations and reject further work.
- [ ] Probe timeout and status checks obey finite deadlines; tests name the production replacement owned by M7.1 so provisional readiness cannot pass release qualification.
