## Outcome

Window snapshots carry compositor identity and geometry without relying on titles or accessibility metadata.

## Milestone

#4

## Dependencies

#22

## Scope

- Promote the pinned kdotool fixed-script probe to a typed adapter on explicit private D-Bus endpoints; asynchronously supervise each subprocess with deadlines and script cleanup.
- Return generation-scoped KWin identity, PID, title/class, client/frame bounds and active focus, representing unavailable metadata explicitly.
- Safely encode data instead of accepting caller JavaScript and associate windows with verified owned application processes. Extend the fixture with dialogs, duplicate titles and unavailable/unassociated metadata cases where feasible.

## Acceptance criteria

- [ ] Real custom-rendered windows/dialogs return expected identities and client geometry without accessibility; duplicate titles remain distinct candidates.
- [ ] Unassociated windows are exposed without false ownership claims; malformed adapter output and slow/hung queries fail explicitly and do not block control-loop cancellation.
- [ ] Query subprocess/script resources are reclaimed on error, timeout and cancellation; dynamic values cannot become arbitrary script source.
