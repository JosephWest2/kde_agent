## Outcome

Close requests normal window closure and reports application exit while leaving confirmation dialogs under caller control.

## Milestone

#4

## Dependencies

#24

## Scope

- Wire close to explicit/unique target resolution, request normal KWin window closure and wait within the shared deadline for tracked application exit.
- Extend the real fixture with close confirmation and refusal/delay cases; return application/window references and remaining process state on timeout.
- Expose a reusable bounded close hook for session shutdown while keeping explicit close semantics independent of shutdown escalation.

## Acceptance criteria

- [ ] Normal close reports observed application exit; a confirmation dialog remains open and discoverable for explicit subsequent input.
- [ ] Close timeout does not send signals, auto-dismiss dialogs or report application exit merely because a window closed. Vanished and ambiguous targets return documented errors.
