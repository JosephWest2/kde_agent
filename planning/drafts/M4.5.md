## Outcome

The separate kill command terminates only verified owned processes and accurately reports remaining descendants.

## Milestone

#4

## Dependencies

#22, #24

## Scope

- Define the finite explicit termination sequence and use tracked kernel process identities and descendant ownership instead of saved PID authority.
- Wait for the tracked application process set, including descendants after original-parent exit, and return exited/remaining process outcomes.
- Add PID-reuse/ownership-race checks and real child/grandchild lifetime cases; distinguish application termination from session-wide systemd cleanup.

## Acceptance criteria

- [ ] A reused PID or unowned process is never signaled; generation mismatch fails before termination begins.
- [ ] Real tracked descendants are terminated or explicitly reported as remaining within the deadline, and subsequent wait/status sees correct exit state.
- [ ] Calling kill is explicit; launch, wait and graceful close failures cannot invoke it automatically.

REQ-015, REQ-016, REQ-020, REQ-022, REQ-035
