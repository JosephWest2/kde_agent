## Outcome

Fresh whole-output pixel data arrives through a validated private capture path that cannot block worker control handling.

## Milestone

#6

## Dependencies

#1, #2, #3

## Scope

- Implement explicit private-bus ScreenShot2 calls, concurrent pipe draining during pending replies, supported metadata/stride/pixel-format validation and Pillow decoding.
- Use the M1-selected execution boundary with enforced deadlines, cancellation and owned pipe/descriptor/task cleanup; disallow personal-desktop fallback.
- Return typed complete image data or stable capture/unsupported/timeout/session errors with side-effect context.

## Acceptance criteria

- [ ] Real headless captures produce correctly decoded whole-output dimensions/colors after the M1 fixture's rendered-state signal.
- [ ] Truncated data, invalid metadata/unsupported formats, hung producer, bus death and cancellation fail within the bound and reclaim owned resources.
- [ ] Slow capture cannot stall control/health processing; a disconnected client does not abandon the adapter's required cleanup.
