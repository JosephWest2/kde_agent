## Outcome

All CLI commands and session lifecycle checks use production behavior with no provisional readiness or shutdown hooks.

## Milestone

#7

## Dependencies

#3, #4, #5, #6

## Scope

- Replace M3's probe adapters with production control/window/resumed-input/fresh-capture probes and wire actual app-close and input-release hooks into bounded shutdown.
- Complete doctor checks for installed versions, user-manager availability and private desktop capabilities, with actionable errors and finite limits.
- Audit command wiring, stable error mapping, partial outcomes and manifest producers across components; enforce noninteractive operation and cleanup independent of the client.

## Acceptance criteria

- [ ] Ready is impossible unless every production probe succeeds; failure in any probe retains diagnostics and invokes bounded cleanup.
- [ ] Stop attempts actual release and graceful close before cgroup escalation; hung/dead helper fallback still works and records truthful outcomes.
- [ ] Every documented command family has a real successful or explicitly unsupported path with valid JSON/errors, and manifests contain all required actual launch/dependency/terminal data.
