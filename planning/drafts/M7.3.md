## Outcome

Automated failures establish generation safety, honest target/process outcomes and cleanup independent of essential processes.

## Milestone

#7

## Dependencies

#36

## Scope

- Create an explicit REQ-038 case index and exercise stale generations after restart, start/stop races, duplicate/conflicting starts, ambiguous/vanished targets and application exit versus window timeout.
- Independently kill worker/compositor/private bus, hang the worker and fail startup; verify unavailable status, client-independent bounded descendant cleanup and durable terminal artifacts.
- Check contaminated host endpoints, protected overrides, different caller cwd, PID reuse, surviving descendants, close confirmation/timeout and explicit-kill remaining-process reporting.

## Acceptance criteria

- [ ] Each listed failure has an identified test and retained evidence; stale commands/fallback cleanup cannot affect a replacement generation or unrelated process.
- [ ] Each essential-process failure leaves no ordinary owned descendants after its deadline, preserves original failure diagnostics and rejects later desktop work.
- [ ] Environment/path tests establish separation and no host fallback. Application handles and uncertain outcomes remain available after timeout/cancellation without automatic retries.
