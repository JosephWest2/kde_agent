## Outcome

Production evidence proves input stopping/release attempts and control responsiveness during slow or failed desktop operations.

## Milestone

#7

## Dependencies

#36

## Scope

- Complete the REQ-038 index with unsupported full text/chords, focus loss, vanished input targets, SIGINT/disconnect and worker timeout during holds and modified typing.
- Exercise real device pause/removal/disconnect using the established procedure, uncertain release, reset during active work and failed reset; supplement with deterministic edge-case doubles only where appropriate.
- Inject slow/timed-out focus queries and blocked/partial capture, queued deadline expiry and stop/reset while active; measure polling, emission-stop/release-attempt, capture and cleanup limits under recorded conditions.

## Acceptance criteria

- [ ] Each required case meets the documented finite bound and records actual timing; failures require fixes or explicitly revised measured limits before support, never silent acceptance.
- [ ] Unsupported requests emit nothing, uncertain release blocks input, failed reset stays unavailable and successful reset waits for resumed devices without replay.
- [ ] Slow capture/query work cannot starve cancellation/stop/health handling, resources are reclaimed and partial images are never successful artifacts; the complete REQ-038 index is satisfied with real lifecycle evidence.
