## Scope

- Write setup and CLI reference with JSON examples, explicit flags/defaults, cwd/PATH/env precedence, protected endpoints, generation-qualified handles and durable artifact retrieval.
- Publish measured deadlines/cancellation and focus polling limits with tested conditions, supported physical keys/chords/US text, client coordinates and reset/uncertain-release troubleshooting.
- Provide a repeatable real-desktop smoke command and supported-versus-deferred scope, trusted filesystem/network access and dispatch-versus-acknowledgment/rendering semantics.

## Acceptance criteria

- [ ] Reproduce installation and the documented workflow from a clean project environment with the required native packages; operations are noninteractive after prerequisite setup.
- [ ] Examples work from a different directory and preserve generations across invocations; smoke output identifies artifacts and meaningful failures.
- [ ] Docs name measured limits and dependency revisions, avoid unsupported application promises, and explain the compatibility checks required after dependency changes.
